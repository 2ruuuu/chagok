# product.md

새 기능 기획하거나 UX 바꿀 때 읽기
여기 방향이랑 맞는지 먼저 확인

## 한 줄

차곡: 영화 티켓으로 관람 인증하고, 본 영화를 카드로 모으는 개인 아카이브

## 배경

- 요즘 영화는 "봤다"보다 "어디서 · 어떤 관에서 · 언제 봤냐"가 더 의미 있어짐
- 예시: '오디세이' 용산 아이맥스 표가 암표로 돌 정도
- 아이맥스, 돌비, 특별관, 재개봉 찾아다니는 사람이 많아짐
- 근데 왓챠피디아, 레터박스드는 아직 "뭘 봤는지 + 별점"만 남김

## 문제

- 기록에 무게가 없음: 별점은 그냥 입력한 숫자라 봤다는 증거가 안 됨, 진짜 증거인 티켓은 버려짐
- 평점을 못 믿음: 안 본 사람도 평점 남길 수 있어서 별점 테러 · 조작이 계속 생김
- 둘 다 원인은 같음 -> 관람한 사실이랑 기록이 따로 놂
- 인증해야만 기록할 수 있게 하면 둘 다 해결됨

## 인증이 번거로운 이유

- 업로드 -> 기다림 -> 실패할 수도 있음, 이 과정을 줄이려고 하지 않음
- 그 번거로움이 카드의 가치를 만듦 (쉽게 얻으면 모을 이유가 없음)
- 등산 정상 인증샷, 스탬프 투어, 러닝 기록이랑 같은 구조
- "왜 이렇게 불편하게 만들었냐"에 답할 수 있어야 함

## 타깃

모든 관객이 아니라 관람 경험을 모으고 싶은 사람

- 특별관 찾아다니는 사람
- 이미 티켓 사진을 인스타 스토리에 올리는 사람
- 극장은 자주 가는데 기록은 꾸준히 못 하는 사람
- 새 행동을 만드는 게 아니라 이미 하는 행동(티켓 사진 찍기)을 서비스 안으로 가져오기

## 목표

- 버려지는 티켓, 24시간 뒤 사라지는 스토리처럼 흩어지는 관람 흔적을 증명 가능한 형태로 남기기
- 오래 쓸수록 가치가 쌓이는 아카이브 만들기

## 아직 안 정한 것

- 티켓 인증 방식

## 알림

- 보낼 알림: 카드 발급, 공지 · 업데이트 (인증 완료 알림은 안 함, 나중에 추가할 수 있음)
- 알림 있을 때 시안은 아직 없음 -> 지금은 /notifications "알림이 없어요" 빈 화면, 종 빨간 점(bell-ring) 숨김

## 영화 데이터 (KOBIS + TMDB)

- 인기 영화: KOBIS 일별 박스오피스 10위
- 곧 개봉: TMDB discover(region=KR, 극장 · 제한 상영) 인기순 20편 중 한국 개봉일이 30일 이내인 영화, 개봉일 가까운 순 최대 10편
  - CGV 상영 예정과 다를 수 있음: TMDB에 한국 개봉일이 없는 영화(한국 · 독립 영화 등) · 인기 20위 밖 영화는 빠짐
  - KOBIS 개봉예정 기준 + TMDB 인기도 방식도 시도했다가 되돌림
- TMDB 키는 "개인 · 비상업 용도"로 발급 -> 광고 · 유료 기능 · 투자 등 수익이 생기면 TMDB 상업 계약(sales@themoviedb.org) 또는 KMDb 전환 검토
- 출처 표시: 설정 화면 하단 (TMDB 로고 + 문구, 영화진흥위원회 통합전산망)
- 지금은 서버에서 바로 호출 + fetch 캐시 (src/lib/movies), 티켓 인증 만들 때 movies 테이블 + 매일 cron으로 전환 예정
- 예매율은 공개 API 없음 (KOBIS 웹 화면에만 있음), 누적 관객 수는 박스오피스 audiAcc

## 카드 받는 순간 연출 (티켓 인증 만들 때 넣기)

- 티켓 인증에 성공해 카드가 생기는 순간, 카드가 한 바퀴 기울며 홀로그램이 반짝이는 애니메이션을 한 번 보여주기
- 이유: 폰에서는 카드 기울임(포인터)이 캐러셀 스와이프에 밀려 거의 안 보임 → "모은 카드의 소장감"을 가장 기대하는 순간에 몰아서 보여줌. 권한 필요 없음
- 만드는 방향: TicketCard의 --px · --py · --rx · --ry · --hyp를 키프레임으로 한 바퀴 돌리는 애니메이션 (포인터 대신 시간으로 같은 변수 움직이기), 한 번만, prefers-reduced-motion이면 생략
- 성능: 계속 도는 게 아니라 한 번이라 괜찮음. 그래도 transform · opacity 위주로 (design-system.md 카드 효과 규칙)
- 같이 검토: 카드 상세(/collection/[cardId])에서 손가락 드래그로 기울이기 (캐러셀 없는 화면이라 touch-action: none 가능)
- 자이로(폰 기울이면 카드 기울기)는 보류: 아이폰 "동작 및 방향" 권한 창 거부감, 누워서 · 걸으면서 볼 때 산만함, 기준 각도 보정 · 끄기 설정까지 작업량 큼. 실사용자 생긴 뒤 설정 토글로 반응 보고 판단

## 리뷰 두 가지 (티켓 인증 때 받음)

- 공유 리뷰 (Ticket.review): 사이트에 공개되는 영화 리뷰, 인증 때 필수. 마이 "관람 리뷰"에 나옴 (홈 "요즘 내가 본" 섹션은 뺌), 카드에는 안 나옴
- 소감 (Ticket.comment): 나만 보는 솔직한 느낌, 카드 뒷면 절취선 아래 밑줄 3칸 (마이 "나의 감상")
- 별점: 인증 때 같이 받음 (컬렉션에 표시)
