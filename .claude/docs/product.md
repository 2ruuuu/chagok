# product.md

새 기능 기획하거나 UX 바꿀 때 읽기
여기 방향이랑 맞는지 먼저 확인

## 한 줄

차곡: 영화 티켓으로 관람 인증하고, 본 영화를 카드로 모으는 개인 아카이브

## 배경

- 요즘 영화는 "봤다"보다 "어디서 · 어떤 관에서 · 언제 봤냐"가 더 의미 있어짐
- 예시: '오디세이' 용산 아이맥스 표가 암표로 돌 정도
- 아이맥스, 돌비, 특별관, 재개봉 찾아다니는 사람이 많아짐
- 근데 왓챠피디아, 레터박스드는 아직 "뭘 봤는지 + 별점"만 남김

## 문제

- 기록에 무게가 없음: 별점은 그냥 입력한 숫자라 봤다는 증거가 안 됨, 진짜 증거인 티켓은 버려짐
- 평점을 못 믿음: 안 본 사람도 평점 남길 수 있어서 별점 테러 · 조작이 계속 생김
- 둘 다 원인은 같음 -> 관람한 사실이랑 기록이 따로 놂
- 인증해야만 기록할 수 있게 하면 둘 다 해결됨

## 인증이 번거로운 이유

- 업로드 -> 기다림 -> 실패할 수도 있음, 이 과정을 줄이려고 하지 않음
- 그 번거로움이 카드의 가치를 만듦 (쉽게 얻으면 모을 이유가 없음)
- 등산 정상 인증샷, 스탬프 투어, 러닝 기록이랑 같은 구조
- "왜 이렇게 불편하게 만들었냐"에 답할 수 있어야 함

## 타깃

모든 관객이 아니라 관람 경험을 모으고 싶은 사람

- 특별관 찾아다니는 사람
- 이미 티켓 사진을 인스타 스토리에 올리는 사람
- 극장은 자주 가는데 기록은 꾸준히 못 하는 사람
- 새 행동을 만드는 게 아니라 이미 하는 행동(티켓 사진 찍기)을 서비스 안으로 가져오기

## 목표

- 버려지는 티켓, 24시간 뒤 사라지는 스토리처럼 흩어지는 관람 흔적을 증명 가능한 형태로 남기기
- 오래 쓸수록 가치가 쌓이는 아카이브 만들기

## 아직 안 정한 것

- 티켓 인증 방식
